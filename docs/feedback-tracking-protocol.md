# Centered feedback-tracking protocol

[Issue #2](https://github.com/czelyk/lugre-iq-budget-lab/issues/2) follows the OP22 receive-side DC diagnostic. All policies now use the same DC estimator on the full recording before running the same feedback channel.

- Reuse the five fixed flight references and the longest 10 ms format prefixes at 480, 720 and 960 kB. Include raw as a control. Condition the reconstructed samples at 4 Msps. For every recording estimate its complex mean from the first 10 ms and subtract it from the complete stream. No per-policy detector tuning.
- Seed the unmodified Pocket SDR Python channel with the external Doppler and code delay. Use one update per millisecond and no repeated acquisitions. The position of the carrier and code replicas in later epochs depends on the channel's feedback. Pocket SDR stays in its FLL pull-in regime on these sub-240 ms prefixes. Python navigation decoding is omitted. The upstream channel requires its navigation interface at startup, so the replay supplies empty initialization methods and raises if any path attempts navigation decoding. The channel's initialized LOCK label gives no measured lock evidence.
- Measure coherence independently from that label. Extend the standard prompt/early/late correlator with six off-code taps at ±80, ±160 and ±256 samples. For each non-overlapping 40 ms window starting at 10 ms, coherently sum each tap in eight 5 ms blocks, then divide summed prompt power by mean summed off-code power. Keep the frequency within ±500 Hz of the initial reference and circular code lag within ±8 samples of the carrier-aided initial prediction in every epoch in that window. Measure the first common 40 ms and consecutive passing milliseconds after the first 10 ms. Process only complete correlator epochs and windows.
- Freeze a single score cutoff as the largest reference-aided 40 ms score across settings on 16 synthetic signal-absent calibration records. Run eight disjoint noise controls and two disjoint signal-present controls at nominal pre-quantization 35 and 40 dB-Hz. Include a separate 40 dB-Hz control with a +500 Hz/s carrier ramp digitally imposed after initial quantization, then requantize. The ramp leaves code acceleration below 0.013 chips over 240 ms. Compare the ramp control's carrier-error trajectory to holding the reference frequency fixed. Use controls to judge whether the tracker can provide actionable evidence for the flight captures. Synthetic noise surrogates cannot establish the field false-alarm rate.
- Separate a byte-budget advantage in available observation time from improved tracking while both formats still have samples. Retain a candidate advantage only if the common 40 ms outcome does not regress and added passing windows recur on at least two recordings. Shortened observation, absent independent flight tracking states, and change across cases limit inference. This test is reference-aided FLL/DLL continuity, with no PLL convergence, unaided lock, or navigation solution claimed.
