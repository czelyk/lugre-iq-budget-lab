# Independent acquisition replay protocol

Fixed before running. The main target is OP76_0, start 960 ms, GPS PRN 32, at the previously observed 1,670,310-byte payload boundary. Repeat OP23_0 GPS 21 at 480,000 bytes and OP2_0 GPS 18 as controls. OP76 GPS 31 is an in-window positive control. Conjugate time reversal of the OP76 lossless stream is a negative control for the original C/A alignment, with no independent estimate of real-world false-alarm rates.

- Feed all recording policies into both stock Pocket SDR Windows CLI (1 ms coherent integration) and a high-sensitivity replay using Pocket SDR's own C/A code generator and FFT correlator (10 ms coherent). Preserve the CLI output as an acquisition diagnostic. The independent high-sensitivity replay is not an unmodified end-to-end Pocket SDR receiver: it uses a custom carrier, coherent folding, code walk compensation, and a nominal screen.
- Score the entire +/-20 kHz by 50 Hz grid in the high-sensitivity replay. Compare the maximum to the mean over the whole code/Doppler plane, a different statistic from the pilot. The nominal per-PRN trial-adjusted gamma cutoff uses 0.001 as an idealized design input. Also test a preassigned 5 ms shift of the coherent grouping, a sensitivity check on the same data.
- Use 4 Msps conditioning for both paths and all policies, and code-phase convention correction for the additional 5 ms. Main target reference is 3400 Hz, sample 760 at 4 Msps from the start. Require a peak within +/-150 Hz and +/-8 samples to call it a match independently of the score. OP23 reference is 6150 Hz, sample 1445; OP2 is -10750 Hz with a Doppler-only cross-check. PRN31 and OP2 are positive controls, not the primary comparison.
- A difference in diagnostic peak or margin alone does not replicate the original decision. Retain the claim only if the independently matched primary target passes lossless and fails both lossy strategies in both coherent groupings, with controls behaving as expected. A reversal or disagreement is decision-sensitive evidence against generalizing the pilot, even if cross-checks still show the same signal peak.
- No carrier or code tracking, analog qualification, packet overhead measurement, or empirical false-alarm calibration in this step. The earlier 1.67 MB boundary was chosen on this same recording and is used for replication, not as a held-out result.
