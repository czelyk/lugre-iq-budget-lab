# Reference-aided sustained correlation protocol

GitHub [issue #1](https://github.com/czelyk/lugre-iq-budget-lab/issues/1). Compare an external code/Doppler handoff on both short common horizons and the available duration. The prior 960 kB experiment compared acquisition, with lossless and low bit depth tied.

## Frozen design

- Allow 480,000, 720,000 and 960,000 packed payload bytes per policy. Replay raw 4-bit per component, level-9 lossless zlib, and reduced 2-bit per component using the existing byte packers. Use the longest whole 10 ms prefix that fits, at most 240 ms. Packet framing is outside the budget.
- Use three earlier comparison captures and two newly used transfer captures with externally published CAF peaks. The per-case approximate Doppler and code delays are fixed in the script. OP32 GPS 6, OP74 GPS 31, OP78_0 GPS 12, OP21 GPS 24 and OP22 GPS 31. A waveform recorded later in the same mission is not independent of its hardware or orbit family.
- Replay each decoded stream at 4 Msps. Using the pinned Pocket SDR L1 C/A code generator, correlate four coherent 5 ms blocks in each non-overlapping 20 ms observation. Search around the external Doppler at ±350 Hz in 50 Hz bins and code delay at ±8 samples. Apply an approximate carrier-derived code walk per block. Compare the local maximum with the same frequency row's off-reference mean, excluding delays within ±32 samples of the predicted peak. The per-window search is repeated around the external seed and has no feedback loop.
- Calibrate a common cutoff on the maximum over all post-warm-up windows, three budgets, and three policies for each of 16 seeded, signal-absent synthetic front-end recordings. Use the largest trial score as the cutoff and keep it fixed for 8 new signal-absent controls, two signal-present controls, and the five flight captures. Synthetic IQ uses seeded complex Gaussian noise plus an off-carrier 420 kHz tone, 8 Msps, and four bits per component. Positive controls use GPS 6 with known phase and constant 1,800 Hz carrier at 40 and 35 dB-Hz before quantization. This calibrated surrogate cutoff gives no field false-alarm rate.
- Discard the first 20 ms from the endpoint. Separately report pass/fail over [20,60) ms (both windows must pass) and the length of the initial consecutive passing run after 20 ms. Report the available whole-window duration so a shorter capture is visible separately from a failed window.
- For a recorder preference, require at least one extra consecutive 20 ms window at the same budget on at least two of five distinct flight captures, with no fixed-horizon regression for that candidate relative to the other. Check positive controls and held-out noise before interpreting flight results. This measure is aided short-snapshot correlation. A receiver FLL/PLL/DLL, bit or frame decoding, and unaided tracking lock are outside the delivered experiment.
