# Frozen-threshold validation protocol

## Fixed inputs and decision rule

- Compare raw, bit-exact zlib at level 9, two bits per I/Q component, and half the sample rate at the original component depth. Give each policy a 960,000-byte I/Q payload allowance, with durations rounded down to 10 ms. Choose the longest lossless prefix that fits, capped at 240 ms. Record the bytes actually used. Packet headers are outside this check.
- Keep the previous coherent replay's 4 Msps ground interface, ±20 kHz by 50 Hz grid, 10 ms coherent dwell, code walk, and per-Doppler-row normalization. Use offsets 0 and 5 ms with equal complete block counts within a policy. Convert each maximum to a common scale using minus log10 of the gamma survival function times the number of searched cells, capped above at one before taking the log. This duration adjustment defines a score. The gamma model supplies no false-alarm guarantee.
- Calibration captures are OP2_0, OP23_0, OP38_0, OP40_0. For each, search eight deterministic artificial codes made by permuting the 1,023 sampled C/A chips before resampling. The codes preserve the chip histogram but are not assigned PRNs. For each capture and code, keep the largest score over both offsets and all policies. Freeze the 95% upper conformal order statistic, rank ceil((32+1)*.95) = 32, before evaluating any held-out targets. Record a separate four-new-code audit per held-out capture. Trials share captures and codes, so the percentage is a calibration target on surrogates, not a field false-alarm rate or a mission requirement.
- Primary held-out operations and references from Daniel Estévez's public analysis: OP32_0 GPS 6 (lunar orbit), OP74_0 GPS 31 and OP78_0 GPS 12 (lunar surface). OP77_1 GPS 6 and 14 are secondary weak-signal cases from the same source. Read approximate delays and Dopplers from the published figures before evaluation. Reduce the delay modulo 1 ms and use ±16 samples at 4 Msps and ±250 Hz for primary matches. For OP77_1 use ±350 Hz because the published peaks spread over several hundred Hz. Matching thresholds do not constrain the search.
- A policy acquires a target for the main decision only when both pre-set offsets match the external peak and independently exceed the same frozen score threshold. Check whether a change in policy changes this decision on more than one primary capture, and whether it survives the held-out wrong-code audit. No tracking-lock, population-level false-alarm, energy, or hardware claims follow from this run.

External reference: [Estévez's LuGRE analysis and CAF figures](https://destevez.net/2025/12/first-analysis-of-the-lunar-gnss-receiver-experiment-data/#results-obtained-with-the-lugre-data). Public captures: [NASA/ASI LuGRE mission data](https://zenodo.org/records/16411687).
